# Ahmed alkholy — Android WebView Chat (PHP/MySQL)

## الاتصال
- واجهة التطبيق تعمل داخل Android WebView.
- واجهة API: https://medoaoft.fwh.is/api/index.php
- تسجيل الدخول وإنشاء الحساب بالبريد الإلكتروني أو رقم الهاتف وكلمة مرور لا تقل عن 8 أحرف.
- يستخدم التطبيق قاعدة بيانات MySQL عبر PHP API، ولا يعتمد هذا الإصدار على Firebase Authentication.

## الوظائف الموجودة في هذه النسخة
- تسجيل الدخول وإنشاء الحساب.
- البحث عن المستخدمين بالاسم أو البريد الإلكتروني أو رقم الهاتف.
- طلبات الصداقة وقبولها.
- المحادثات الخاصة والرسائل النصية.
- نشر الحالات النصية التي تنتهي بعد 24 ساعة.

## ملاحظات
- هذه نسخة تجريبية (debug) وليست إصداراً نهائياً موقعاً للنشر.
- رفع الصور داخل المحادثات غير متاح في واجهة هذه النسخة بعد، رغم أن API يحتوي على مسار upload_image.
- المكالمات الصوتية والإشعارات الفورية غير متاحة في هذه النسخة.
- يلزم وجود اتصال إنترنت للوصول إلى الخادم.


## إصلاحات إصدار التشخيص
- استبدال AppCompatActivity بـ Activity لتقليل اعتماد بدء التشغيل على مكتبات الواجهة.
- إضافة شاشة خطأ عربية بدلاً من الإغلاق الصامت عند تعذر تحميل صفحة التطبيق أو توقف محرك WebView.
- إضافة حفظ واستعادة حالة WebView وتنظيفه عند إغلاق النشاط.
- لم يتم تغيير رابط PHP API أو ملفات الواجهة أو قاعدة البيانات.
- هذه نسخة مصدرية معدلة؛ لم يتم إنشاء APK هنا لعدم توفر Android SDK وGradle في بيئة البناء.
